CE203 APPLICATION PROGRAMMING LAB 6

The aim of this lab is to explore both the Java collections framework and exception handling, as well as recapping earlier material from the course.

Download the file Lab6.java into your area (there is also an IntelliJ project you can download if you prefer).

EXERCISE 1

Lab6.java contains a main method that will input students' names and marks from the keyboard and store them in a map. Examine the program and compile and run it.

We wish to display the marks one student per line in the form

Bob: Age = 55
Ann: Age = 72

Write a method which takes an argument of type Map<String,Integer> and uses an iterator for the map's entry set to print the marks in the required format.

Change the last line of the main method so that it calls your new method instead of printing the map directly.

Compile and run.

EXERCISE 2

We now wish to add methods to calculate the median average mark obtained by the students and to find the student with the lowest mark.

Write a method which takes an argument of type Map<String,Integer> and uses an iterator for the map's values collection to calculate the total of the marks. The method should then calculate the median of the marks and return the result.

Add code to the end of the main method to call the new method and print the result that it returns.

Compile and run.

Write a method which takes an argument of type Map<String,Integer> and uses an iterator for the map's entry set to find and return the entry with the lowest mark. (The method should return a result of type Map.Entry<String,Integer>)

Add to the end of the main method code to call the method and print its result.

EXERCISE 3

We now need to handle exceptions in the case of invalid entries in the map. Student marks should always be a percentage in the range 0 to 100. In the case of a negative student mark or a mark above 100 in the map an InvalidNumberException should be thrown. Add exception handling to each of the methods developed in exercise 2 to handle negative numbers.

Design a testing strategy for this exception handler and describe this in your lab report.
