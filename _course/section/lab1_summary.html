EXERCISE 3

Create a new application to hold details of vehicles used by an organization. The organization will use vehicles in three different roles: delivery, people transport, and construction. Start by creating an abstract class ‘vehicle that contains information that is true for all types of vehicle (e.g. names, types, MPG etc.). Then extend this abstract class to create three new classes, one for each type of vehicle. These new classes should hold information that is specific to each vehicle type (e.g. number of miles driven by each vehicle in delivery).

Add an abstract method to the abstract vehicle class with the name ‘information’. Create fully-implemented versions of this method in each of the classes that extend the vehicles class. Within the body of these methods essential information about the values assigned to the instance variables within each object should be printed.

Write a main method to test your code.

Describe your program in your report.
