Module Information

Check the Module Directory here.

This module extends the student's knowledge and skills in object-oriented application programming. Further Java programming language principles and the use of Application Programming Interfaces (APIs) are explored supported through reference to Unified Modelling Language (UML) and design patterns.

The module will give students core programming skills that are required for Years 2 and 3 of the Computer Science degree schemes.

Java Graphical User Interface (GUI) Swing and AWT APIs are practically examined in some detail. The Java Collections API is explored with emphasis on how to utilise these classes in programs to best effect. Students will also be introduced to third-party APIs, since an important part of application programming is the process of understanding and using such APIs.

The Module will be assessed by coursework and examination. The coursework is worth 40% of the module mark (broken down into: Progress test = 10% and one Programming Assignment worth 30%. Please see the coursework section for further details. The examination is worth 60% of the module mark and will be a 120 minutes exam which will take place in the summer. 

Reassessment on this module will be based on one piece of coursework comprising of a practical  programming assignment worth 40% of the resit module mark and a 120 minutes resit exam worth 60% of the resit module mark.

Revision and example Questions
        
Revisions Tips:

Object instantiation using ‘new’ and use of constructors including super() for class hierarchies.

Knowing the difference between source and class files in Java.

Primitive data types and static arrays

Using pointers (references) to objects using ‘this. We covered this in the lab exercises.

Difference between abstract classes and interfaces and how to define each (extends vs implements)

Difference between method overloading and method overriding and related to this the difference between static and dynamic binding which is linked to polymorphism.

In OOP what are accessor and mutator methods.

Access modifiers in Java what are the differences (public, protected, private, none).

General differences between layout managers that were introduced (Box, Gridbag, Border, Flow, and Grid). Also what is the default layout manager.

Understanding class hierarchies and inheritance. Remember we use the keyword extends.

Basic UML associations: aggregation, composition, realisation, generalisation.

Java Swing ActionListener definition and use, see your code examples from lab exercises / solutions.

Basics of Java Swing components based on components introduced.

What is the idea of event driven programming.

List based data structures available in the Java Collections framework and key methods that can be used to manipulate contents.

Definition and use of iterators for traversing through a Java collection.

Exception handling, in particular understanding execution paths resulting exceptions being thrown by and method and caught using a try catch block

How does the paintComponent() method from JPanel work when used to draw single graphics on screen.

Interpreting basic UML class diagrams.
